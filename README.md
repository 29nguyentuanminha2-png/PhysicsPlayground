# Physics Playground 🎮

A 3D physics-based game built with Unity as part of my 
6-month Unity/XR developer learning journey.

## What I Built
- Ball controller with WASD movement and jump
- Physics-based ramp and moving platform
- Collectible coins with score system
- Countdown timer with Win/Lose conditions
- Audio feedback and restart functionality

## What I Learned
- Unity fundamentals: GameObject, Component, Prefab
- C# scripting: MonoBehaviour, Rigidbody, Colliders
- Physics system: Trigger vs Collision detection
- UI system: TextMeshPro, Canvas, Button
- Git workflow for game development

## Built With
- Unity 2022.3 LTS
- C#
- Built-in Render Pipeline

✅ Complete — Day 1–5 of learning journey
